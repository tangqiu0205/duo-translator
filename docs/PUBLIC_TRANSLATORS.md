# 哔哩与豆包翻译

在设置 → 翻译服务中管理服务，可用于网页、划词、输入框、Popup 文本和字幕翻译。

## 哔哩翻译

- 无需 API Key，不使用 B 站登录 Cookie；原文会发送至哔哩翻译服务。
- 点击服务行的“编辑”选择模型：`Index-Translate-35B-A3B`（默认）、`index-mt-9b`、`index-mt-2b`。

## 豆包翻译

- 需要先在同一浏览器登录 https://www.doubao.com/；请求使用浏览器登录态，不读取或导出 Cookie 字符串。
- 豆包、豆包·火山、豆包·微软均经豆包后端处理，并非分别直连火山或微软 API；客户端无法确认实际使用的模型。
- 源语言仅支持自动识别；不支持的目标语言会报错。

## 隐私与限制

- 点击服务行的“测试”会实际发送 `Hello, world.`；保存模型不会发送翻译请求。
- 网页自动语种检测可能调用 Microsoft；Popup 文本翻译不会为补全源语言额外发送原文，源语言未知时禁用原文朗读。
- 浏览器必须支持所需请求头规则，豆包登录态还受浏览器 Cookie 策略影响。
- 这些服务不是有稳定性承诺的开放平台 API，可能限流、风控或停用。目前仅通过模拟请求测试，未使用用户账号联网实测；请遵守服务商规则。
